# Outlier Template Index

Use these templates when a report should look memorable and finance-native without defaulting to a conventional grid of cards. Commonness scores estimate how often a user has likely seen this kind of report aesthetic, ordered from most common to least common within each group.

## Full-Page Layouts

- `58% common` - `institutional-tear-sheet.html`: editorial broker-note layout with restrained asymmetry, strong tables, and print-friendly colors.
- `34% common` - `exchange-floor-ledger.html`: loud exchange-floor notice board with tape strips, stamps, and margin annotations.
- `19% common` - `orbital-risk-map.html`: circular/orbital market structure with strike rings, regime satellites, and radial legends.
- `7% common` - `spectral-liquidity-lab.html`: scientific lab-plate treatment with ultraviolet gradients, specimen tags, microscope grids, and irregular charts.

## Visualization Fragments

- `62% common` - `visual-fragments.html#stratified-bars`: stacked horizontal strata for GEX, volume, or fundamentals contribution.
- `41% common` - `visual-fragments.html#tape-river`: price/history ribbon that bends through annotated regimes.
- `23% common` - `visual-fragments.html#option-constellation`: radial option/strike constellation for resistance, support, and pivot nodes.
- `11% common` - `visual-fragments.html#liquidity-fossil`: fossil/sediment core metaphor for strike-by-strike pressure.

## Palette Families

- `66% common` - `Sovereign Desk`: navy, ivory, oxblood, muted gold. Good for professional reports that still need personality.
- `49% common` - `Circuit Pit`: graphite, electric cyan, safety orange, exchange green. Good for active trading and options reports.
- `31% common` - `Miso Macro`: warm paper, black sesame, ume red, matcha green. Good for calm macro/fundamental reports.
- `17% common` - `Polar Auction`: ice blue, seal black, aurora green, magenta stamp. Good for futures, rates, and liquidity auctions.
- `8% common` - `Ultraviolet Specimen`: ink black, ultraviolet, reagent yellow, arterial red. Good for rare, high-impact market-structure pieces.
- `3% common` - `Desert Exchange`: sand, iodine blue, cactus green, rust, bone. Good for cartographic or field-report motifs.

## Selection Rules

- If the user needs credibility and stakeholder readability, start with `institutional-tear-sheet.html` or `Sovereign Desk`.
- If the user wants something bold but still obviously trading-related, use `exchange-floor-ledger.html` or `Circuit Pit`.
- If the report centers on levels, flows, or structural relationships, use `orbital-risk-map.html` or the radial fragments.
- If the user asks for rare, striking, or memorable output, use `spectral-liquidity-lab.html`, `Ultraviolet Specimen`, or `Desert Exchange`.
- Avoid using more than one full-page concept in a single report. Mix fragments only when their metaphor supports the same story.
